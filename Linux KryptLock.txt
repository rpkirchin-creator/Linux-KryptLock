Yes — Ubuntu Files (Nautilus) automatically adds any executable script placed in ~/.local/share/nautilus/scripts/ to your right-click menu under Scripts.
I updated the .deb installer and CLI so this is built in now, and you can also set it up with a quick command:
Option 1: Rebuild & Reinstall the Updated .deb (Recommended)
The updated .deb now installs the right-click scripts automatically during apt install and adds kryptlock-gui --pack support so right-clicking multiple files or folders opens Pack & Lock with them already queued:
Bash
npm run build:deb && sudo apt install -y ./kryptlock_1.0.0_all.deb
You can also re-create the menu entries anytime with:
Bash
kryptlock install-context-menu
Option 2: Run the Context-Menu Script Directly on Ubuntu
If you want to add the right-click entries directly from your Ubuntu terminal:
Bash
mkdir -p ~/.local/share/nautilus/scripts
cat <<'EOF' > ~/.local/share/nautilus/scripts/"Lock with KryptLock"
#!/usr/bin/env bash
set -euo pipefail
if [ "$#" -gt 0 ]; then
  exec kryptlock-gui --pack "$@"
else
  exec kryptlock-gui
fi
EOF
cat <<'EOF' > ~/.local/share/nautilus/scripts/"Unpack with KryptLock"
#!/usr/bin/env bash
set -euo pipefail
if [ "$#" -gt 0 ]; then
  exec kryptlock-gui "$1"
else
  exec kryptlock-gui
fi
EOF
chmod +x ~/.local/share/nautilus/scripts/"Lock with KryptLock" ~/.local/share/nautilus/scripts/"Unpack with KryptLock"
(Note: --pack multi-file pre-staging requires the updated .deb above; if you run this before updating, Unpack with KryptLock works immediately on archives.)
How to Use It in Ubuntu Files
Right-click any file(s) or folder(s) → Scripts → Lock with KryptLock
Right-click any .klock, .rar, .7z, .zip, .tar.gz, .bz2, or .xz archive → Scripts → Unpack with KryptLock (or Open With… → KryptLock)

Because a downloaded project folder doesn't come with .git initialized yet, publishing to GitHub from Ubuntu/VS Code usually fails for one of three reasons: no git identity configured, no local commit/repo initialized, or GitHub HTTPS password auth rejected (GitHub requires a token, SSH key, or GitHub CLI/VS Code login instead of your GitHub password).
Step 1: Initialize & Commit in Your VS Code Terminal
Run these in your project folder in Ubuntu/VS Code (replace with your name and GitHub email):
Bash
git init -b main
git config user.name "Your Name"
git config user.email "your-github-email@example.com"
git add .
git commit -m "Initial commit: KryptLock"
(If git init -b main fails on an older Git version, run git init && git branch -M main.)
Step 2: Push to GitHub
Option A — Easiest via GitHub CLI (gh)
Bash
sudo apt install -y gh
gh auth login
gh repo create kryptlock --private --source=. --remote=origin --push
(Change --private to --public if you want a public repo.)
Option B — Push to an Empty Repo You Already Created on github.com
Make sure the new repo on github.com was created empty (no README/license added on github.com).
Copy the repo URL and push:
Bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
When prompted for Password, do not enter your GitHub account password — paste a GitHub Personal Access Token (PAT) (github.com → Settings → Developer settings → Personal access tokens), or use VS Code's Source Control → Publish to GitHub after clicking the bottom-left Accounts icon to sign in with GitHub.
Common Errors & Quick Fixes
rejected ... fetch first (you created a README/license on github.com first):
Bash
git pull origin main --allow-unrelated-histories
git push -u origin main
Support for password authentication was removed: Use gh auth login (Option A) or a GitHub Personal Access Token instead of your account password.
Author identity unknown: Run the git config user.name and git config user.email commands in Step 1.
