2. How VS Code Edits & npm install Affect the .deb File
Short answer: Running npm install in VS Code does not update kryptlock_1.0.0_all.deb or update the app installed on Ubuntu.
What npm install does: It only reads package.json / package-lock.json and installs Node dependencies into node_modules/.
Why Ubuntu won't see your edits automatically: A .deb archive is a static snapshot generated at build time, and apt / dpkg copies its scripts into /usr/share/kryptlock/ and /usr/bin/ rather than linking back to your VS Code folder.
To apply edits made in VS Code (src/lib/linuxAppSource.ts or src/lib/debBuilder.ts) to your .deb and Ubuntu system:
Rebuild the .deb file (either in the VS Code terminal or from the web UI):
Bash
npm run build:deb
(Or run npm run dev and click Download Ubuntu .deb in the browser.)
Reinstall / upgrade the .deb on Ubuntu:
Bash
sudo apt install -y ./kryptlock_1.0.0_all.deb
